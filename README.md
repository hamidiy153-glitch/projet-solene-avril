# Projet Fil Rouge - Portfolio Solène Avril

Intégration d'une maquette responsive (vues mobile, tablette et ordinateur) pour le portfolio fictif de la photographe d'art **Solène Avril**, réalisée dans le cadre du module HTML / CSS.

## Aperçu en ligne
Le site est hébergé et accessible via GitHub Pages à l'adresse suivante :  
👉 [Voir la page Web sur GitHub Pages](https://github.io)

## Langages et outils utilisés
* **HTML5** : Structure sémantique de la page.
* **CSS3** : Mise en page avec Flexbox et CSS Grid, gestion du responsive via les Media Queries.
* **Google Fonts** : Intégration des polices *Yeseva One* et *Montserrat*.
* **Font Awesome** : Intégration des icônes des réseaux sociaux.
* **Lorem Picsum** : Génération des images aléatoires de la galerie.
